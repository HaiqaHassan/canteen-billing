
# Campus Canteen Billing System

## Project Description
A simple Python program that calculates a customer's
canteen bill. Customers can order multiple items and
checkout when they finish ordering.

## Menu and Prices
- Tea: PKR 80
- Sandwich: PKR 250
- Juice: PKR 150
- Coffee: PKR 180

## Discount Rule
A 10% discount is applied when the subtotal is
PKR 1,000 or more. Otherwise, no discount is applied.

## Features
- Displays a menu of four items
- Accepts item selections and quantities
- Supports multiple orders
- Calculates subtotal and total quantity
- Applies the discount when eligible
- Displays the final bill

## Requirements
Python 3

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   python3 billing.py

## Concepts Used
Variables, print(), input(), operators, if/elif/else,
while, break, and continue.

## Note
All prices are fictional and used for classroom examples.
